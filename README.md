Bengaluru House Price Prediction

Project Overview

This project analyzes Bengaluru real estate data and uses machine learning to predict house prices.

Tools Used

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* SQL
* Power BI
* Scikit-learn
* Jupyter Notebook

Project Steps

1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. SQL queries and analysis
4. Power BI dashboard creation
5. Machine learning model development
6. House price prediction

Machine Learning Models

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor
* K-Nearest Neighbors Regressor

Results

My initial Random Forest model achieved an R² score of 0.759 and a mean absolute error (MAE) of approximately 20.1 lakhs.

The model predicted approximately ₹49.94 lakhs for a hypothetical 2-BHK house in Whitefield with 1,200 sq. ft. and two bathrooms.

Predictions are estimates and not guaranteed market prices.

Conclusion

This project helped me practice data cleaning, data visualization, SQL analysis, dashboard development, and machine learning regression.
